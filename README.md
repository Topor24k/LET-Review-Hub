# LET Review Hub 📚🎓

An editorial-style, structured review portal designed for the **Licensure Examination for Teachers (LET)** in the Philippines. It covers comprehensive review materials, active recall drills, flashcards bank, and timed exam simulations for both **Professional Education** and **General Education** subjects.

---

## ✨ Features

- **📖 Editorial Substack-Style Study Portal**: Clean, distraction-free reading experience for all LET subjects.
- **📝 Comprehensive Subject Coverage**:
  - **Professional Education**: Child & Adolescent Development, Curriculum Development, Assessment of Learning, Methods & Strategies, Building & Enhancing Literacies, Social Dimensions of Education, Educational Technology, Inclusive Education, and Teaching Profession/Ethics.
  - **General Education**: Mathematics, Filipino, Purposive Communication, Art Appreciation, Ethics, Rizal's Life & Works, Science, Technology & Society (STS), Understanding the Self, and Social Studies.
- **⏱️ Timed Exam Simulations**: Realistic mock exam practice with timer, instant rationale/explanations, and score performance history.
- **💡 Interactive Highlights & Flashcards Bank**: Multi-color highlighting, question conversion drills, and custom flashcards creation.
- **🔒 Passcode-Protected Access**: Single-user local session protection with passcode unlock.
- **📱 Fully Responsive**: Optimized for desktop, tablet, and mobile viewing.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- `npm`, `pnpm`, or `yarn`

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Topor24k/LET-Review-Hub.git
   cd LET-Review-Hub
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:3000`.

## 🌐 Deploy to Vercel

This application is ready for 1-click deployment on [Vercel](https://vercel.com/):

### Option 1: Deploy via Vercel Dashboard (Recommended)
1. Push your repository to GitHub: `https://github.com/Topor24k/LET-Review-Hub`.
2. Log in to [Vercel](https://vercel.com/).
3. Click **"Add New..."** > **"Project"**.
4. Import `LET-Review-Hub`.
5. Framework Preset will automatically detect **Vite**.
6. Click **Deploy**.

### Option 2: Deploy via Vercel CLI
```bash
npm i -g vercel
vercel
```
